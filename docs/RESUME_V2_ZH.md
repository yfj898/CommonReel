# CommonReel 可核对的简历素材

建议使用已实现的工程内容，不把待验证的用户效果写成结果。

- 使用 Go、SQLite WAL 和官方 MCP Go SDK 实现多人选片服务，统一 HTTP 与 MCP 业务规则；通过房间版本与决定版本分别处理 CAS 和表态失效，避免单人表态清空其他记录。
- 实现最小幂等回执、20 个同请求并发重试、竞争写与重启恢复；保存前在事务外刷新供应，再校验版本，拒绝网络等待期间产生的过时决定。
- 构建 247 部 Wikidata 可核对电影目录，接入真实美国流媒体供应；区分订阅、租赁、购买和未知状态，按需查询、限额、缓存并严格排除不满足条件的影片。
- 实现缓存只读片长试算，对完整目录计算前后可行集合与新增数量；显式应用使用房间版本、目录/供应事实及有效期绑定，复用事务与幂等回执，拒绝过时预览。
- 接入零费用本地模型，通过真实 MCP 调用修改条件、推荐与解释；发现平台幻觉后，改为由 Go 展示工具事实，区分模型调用和程序补做的核实调用，并保留失败与修复后的实测证据。
- 实现可选 Netflix CSV 规范化导入、恢复码画像、当晚副本、删除撤回及 24 小时清理；不将观看记录直接当作喜欢，原始 CSV 不保存。

范围必须说明：Chromium 两种 origin、360/390 触摸模拟与 319/1280px 布局、2/3/4 成员流程已检查；真实手机未测；暂无真实小组试用；源码已公开；公开视频由本人上传，最终比赛提交未完成，不写成“已参赛获奖”或“已上线”。旧 MovieLens user-kNN 结果属于独立离线研究，不是新流程的群体效果。

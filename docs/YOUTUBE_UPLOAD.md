## Description

CommonReel helps 2–4 adults choose a film together on the same Wi-Fi.
Explore a larger runtime without changing the room, then explicitly apply it,
record each member entry's response, and save after current supply is checked.

This 90-second silent demo has English captions embedded in the picture. It
shows the running Go application, a free local Qwen model
calling a real MCP 2025-11-25 Streamable HTTP tool, and a second-origin LAN
client updating. The recorded preview changes an 81-minute limit to a
hypothetical 96 minutes: 0→19 eligible films, 19 newly eligible, six displayed.
Inside Out 2 is then saved as a group-recorded choice.

Source and run instructions: https://github.com/yfj898/CommonReel
Tools, data and acceptance: https://github.com/yfj898/CommonReel/tree/main/docs

# Thirty recent films — reviewed provenance, 2026-10-21

The addition is integrated into the 247-film catalog. The original 217 Film
objects and identifiers are retained; all 30 new QIDs and IMDb IDs are unique.
Actual added years are **2015–2024**, within the approved 2015–2025 boundary.

## What was verified

Each fixed QID has an English label, exact P345 IMDb identifier, earliest non-
deprecated P577 year, exactly one positive P2047 duration in unit Q7727 (minute),
explicit P136 genres and a film / animated-film P31 claim. Conflicting or non-minute
runtime values are excluded. P31 animation does not imply an Animation P136 genre.
The neutral catalog prior remains 3.0 and the existing Film version rule is used.

Structured data comes from the [official Wikidata Entity API](https://www.wikidata.org/w/api.php?action=help&modules=wbgetentities)
under [CC0](https://www.wikidata.org/wiki/Wikidata:Licensing). These are exact
QID/IMDb joins, not title-similarity joins or a separate IMDb account/API query.
Years follow the earliest source statement, not specifically US release year.
No supplier/model calls, film posters, trailers or streaming responses are included.

## Reproduce from the project root

```powershell
python scripts/build-catalog-entities.py --modern-only
```

This offline command uses `assets/catalog-sources/modern-2026-10-21`: fixed
`modern-seeds.json`, `modern-genre-map.json`, `base-catalog-identifiers.json`,
the retained genre map, `raw-sources.json` and seven original responses in `raw/`
(9,866,996 bytes). `source-audit.json` and `candidate-audit.json` preserve the
per-item facts and exclusions. Output goes to `data/catalog-v2.json` and its
manifest; review and copy both to `assets/`. The 217 base Film objects remain
unchanged. `scripts/build-modern-catalog.py` performs the strict 30-film rebuild.

`scripts/collect-modern-catalog.py` documents the same official requests and
reuses retained responses. For a new upstream snapshot, use a separate project
copy and preserve this frozen evidence; new facts may fail the fixed-seed or
unique-runtime checks and require reviewed replacements.

Subscription availability remains a separate Watchmode check. API eligibility,
legacy watched matching, cached preview behavior and bilingual UI have their
own engineering and browser evidence in the October 21 release report.

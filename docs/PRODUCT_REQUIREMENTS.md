## 产品定位与成功结果

CommonReel 面向有共同观影习惯的 2–4 名成年室友或朋友，让他们在同一地点通过各自手机维护选片条件，在可核对电影中筛选候选，并保存小组记录的选择。首要目标是在 Amazon 比赛截止前交付完整可演示作品，同时形成有实际证据的 Go 工程成果。

任何成员都可以代别人修改、表态或作决定。保存要求每个成员条目均标为接受，但不证明每个人本人同意，也不是群体满意度证据。主要工程结果是已记录条件得到满足、多人状态一致且选择有清楚的记录。

目前没有真实测试者。目标人群、痛点频率、导入意愿、重复使用及节省时间均是待验证假设。真实数据评价和工程测试不能替代用户研究。

## 当晚使用场景

三位室友晚饭后准备共同看电影。创建者分享链接或二维码，各人的手机与服务电脑处在同一 Wi-Fi。大家填写今晚共同设备可用的平台和片长上限；成员填写或代录类型偏好、否决与已看，可导入 Netflix CSV，也可用恢复码载入长期画像。

系统筛掉未知或不满足条件的影片，提供少量候选与事实、估计依据。小组通过页面或对话调整条件；归属不清时助手追问。无结果时显示资料不足或条件冲突，等待明确修改。各成员条目均标为接受后，页面保存小组记录的选择。

成员、偏好、历史或硬性条件改变后，旧接受记录失效并重新表态。实际播放与账户权益由用户在平台核对，产品结束在协商和选择记录。

## 首版范围

| 功能 | 必须达到的行为 |
|---|---|
| 局域网手机加入 | 链接与二维码，2–4 名成员，共享编辑与代操作，变更同步、断线恢复 |
| 历史导入 | Netflix CSV 可跳过；可靠匹配电影才计入已看；重复、剧集、歧义、库外与未匹配条目有报告和确认入口 |
| 长期画像 | 保存规范化已看、必要待确认标题、明确评分/喜欢和稳定类型偏好；原始 CSV 不保存；恢复码加载/更新/删除，无注册账号 |
| 当晚资料 | 使用长期画像副本；共享代修改不自动写回长期画像；临时否决、片长、平台、表态属于当晚 |
| 硬筛选 | 类型否决、最长片长、美国订阅供应、已看/重看；未知或不满足均排除 |
| 候选与解释 | 目录约 200–300 部，明示覆盖；事实、推荐估计、过滤理由、应用查询时间和未知项清楚 |
| 本地代理 | 零费用本机模型经 Go MCP 修改明确条件/偏好、重新推荐和解释；归属不清追问 |
| 选择记录 | 表态、保存、删除走页面按钮；全部成员条目标为接受才保存；关键输入变化使旧接受失效，保存再检条件 |
| 生命周期 | 场次结束或创建后 24 小时过期，清理成员、临时偏好、历史副本；选择只留无姓名/历史的摘要；长期画像保留到主动删除 |
| 画像删除 | 撤回长期资料、缓存、活动场次关联资料与响应残留，使旧接受失效 |

恢复码提供长期资料维护的持有权，不证明现实身份。房间邀请只提供该场次共享操作，不能枚举或覆盖其他长期画像。

## 确定的条件语义

- 片长上限与平台集合属于房间，平台表示今晚共同设备可用的服务。
- 合并成员类型否决，任一命中即排除。类型标签不保证惊吓、情绪或年龄适宜性。
- 禁止重看时，排除任一人的明确已看或可靠历史匹配。未匹配、无历史只能称没有已知匹配，不能称从未看过。
- 影片须满足时长上限，并在至少一个勾选平台有美国订阅供应；租赁、购买不混作订阅，供应不保证个人账户免费权益。
- 看过不等于喜欢、看完、满意；偏好使用明确评分、喜欢或类型偏好。保存选择不自动加入已看。
- 时长、供应未知或过期无法重新确认时排除；无结果不自动放宽硬条件。事实改变使已选影片不再满足条件时需重新筛选、表态。
- 长期画像写回需要恢复码持有者明确操作；匹配只检索必要片名/年份，不上传完整历史。

## 运行和数据依赖

模型调用和数据服务新增付费预算均为零，使用现有电脑，不依赖付费 API、订阅或新购硬件。优先实测 Ollama＋qwen3.5:4b，必要时替换其他免费工具调用小模型。硬件已读到 RTX 5060 Ti 约 16GB 显存、约 16GB 系统内存；没有成功推理、GPU offload、准确率、时延或并发证据。

模型提出工具调用，由 Go 校验参数、执行 MCP、维护状态和筛选。代理步骤/等待有上限；错误、超时或不可运行时明确报错，表单可独立完成流程。每轮只提供任务需要的上下文，不把完整长期历史塞进提示词，不用固定脚本冒充模型成功。[Ollama 工具调用](https://docs.ollama.com/capabilities/tool-calling)、[模型候选](https://ollama.com/library/qwen3.5)。

| 数据来源 | 用途与边界 |
|---|---|
| Wikidata | CC0 片名、标识、类型、片长；缺字段、单位/版本、标识匹配需验证；不提供完整实时美国供应 |
| Watchmode 免费 API | 美国订阅供应，需 key、署名、遵守额度和缓存条款；原始供应响应留在应用内，不随源码分发、不发给第三方模型；实际请求待验证 |
